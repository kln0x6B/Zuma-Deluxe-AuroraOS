# Zuma Deluxe AuroraOS

Порт игры [Zuma Deluxe HD](https://github.com/GalaxyShad/Zuma-Deluxe-HD) на ОС Аврора.

Zuma Deluxe HD — ремейк классической игры PopCap Games 2003 года, созданный
GalaxyShad и s4lat. Этот проект переносит игру на ОС Аврора: движок переписан
на Qt Quick, добавлено сенсорное управление и поддержка экранов любых пропорций.

* Автор порта: Kirill Koleno (https://github.com/kln0x6B)
* Исходный проект: https://github.com/GalaxyShad/Zuma-Deluxe-HD

## Требования

* ОС Аврора 5.1 или новее.
* Архитектура `armv7hl` (например, Fplus R570E) или `aarch64` (например, планшет KVADRA_T).

## Установка

Готовые пакеты публикуются на странице
[релизов](https://github.com/kln0x6B/Zuma-Deluxe-AuroraOS/releases).
Скачайте пакет для архитектуры своего устройства:

| Архитектура | Файл |
|---|---|
| 32-битные устройства | `ru.kln0x6b.AurZuma-<версия>.armv7hl.rpm` |
| 64-битные устройства | `ru.kln0x6b.AurZuma-<версия>.aarch64.rpm` |

Архитектуру устройства можно узнать командой в терминале:

```bash
rpm -q --qf "%{ARCH}\n" glibc
```

Пакеты подписаны ключом разработчика, а не ключом магазина приложений,
поэтому перед установкой нужно подготовить устройство:

1. Включите режим разработчика:
   «Настройки → Инструменты разработчика».
2. Разрешите установку приложений не из магазина и отключите проверку
   (валидацию) устанавливаемых пакетов в разделе «Инструменты разработчика».
3. Скопируйте пакет на устройство и откройте его в приложении «Файлы»,
   либо установите из терминала:

   ```bash
   devel-su pkcon install-local ru.kln0x6b.AurZuma-<версия>.<архитектура>.rpm
   ```

Для обновления установите пакет новой версии тем же способом.
Чтобы удалить игру, удерживайте её значок в меню приложений и выберите «Удалить».

## Управление

* Коснитесь экрана, чтобы прицелиться, и отпустите палец, чтобы выстрелить.
* Коснитесь лягушки, чтобы поменять текущий и следующий шары местами.
* Кнопка «MENU» в правом верхнем углу открывает паузу и настройки громкости.
* Кнопка «MORE GAMES» в главном меню показывает авторов и лицензии.
* При сворачивании игра встаёт на паузу.

## Сборка

Проект собирается [Аврора SDK](https://developer.auroraos.ru/doc/sdk) 5.2.1 или новее.

В Аврора IDE откройте `ru.kln0x6b.AurZuma.pro` и соберите проект для нужной
архитектуры. Из командной строки (Аврора SDK Build Tools):

```bash
tools/release.sh --build-only
```

Готовые пакеты появятся в каталогах `build/armv7hl/RPMS` и `build/aarch64/RPMS`.

Приложение использует только системные библиотеки из списка разрешённых
зависимостей ОС Аврора: Qt 5.6 (Qt Quick, Qt Multimedia), Sailfish Silica
и `libvorbisfile`.

## Ресурсы игры

Каталог `data/` собирается из исходного проекта скриптом:

```bash
tools/import_assets.sh <путь к клону Zuma-Deluxe-HD>
```

Скрипт копирует используемые изображения, шрифты, уровни и звуки и переводит
музыку из `zuma.mo3` в дорожки Ogg Vorbis (нужны `openmpt123` и `oggenc`).

## Структура проекта

| Каталог | Содержимое |
|---|---|
| `src/engine` | Движок: отрисовка через граф сцены Qt Quick, растровые шрифты, звук, ввод, хранение настроек |
| `src/game` | Игровая логика: уровни, цепочка шаров, лягушка, снаряды, эффекты |
| `src/ui` | Игровой интерфейс: кнопки, ползунки, диалоги, экраны меню |
| `qml` | Окно приложения, игровая страница, обложка |
| `data` | Ресурсы игры |
| `rpm` | Спецификация пакета, история изменений и манифест совместимости |
| `tools` | Импорт ресурсов и публикация релизов |
